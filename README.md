# Tourist App

Tourist App is an Android application built using Kotlin and Android Studio. 
The app displays tourist destinations with images, names, and descriptions.

## Features

- Displays tourist destinations
- Uses RecyclerView
- Includes destination images
- Has a search function
- Simple and user-friendly design

## Technologies/tools Used

- Kotlin
- Android Studio
- XML
- RecyclerView
